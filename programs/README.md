# programs

An entry for Herdr's program table so [omp](https://github.com/can1357/oh-my-pi) panes show a π icon everywhere (tab bar, agents list, pane headers).

```sh
mkdir -p ~/.config/herdr-app/my-icons
cp omp.svg ~/.config/herdr-app/my-icons/
cp programs.json ~/.config/herdr-app/   # or merge its "omp" entry into yours
```

No `programs.error` file means it loaded.
